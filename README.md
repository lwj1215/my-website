# 采购管理系统

一个完整的、可更新的采购表格管理系统，支持采购记录的添加、编辑、删除和查看。

## 功能特点

- ✅ **客户姓名**：记录客户的姓名
- ✅ **订单号**：唯一标识每个订单
- ✅ **采购商管理**：支持记录多个采购商，每个采购商对应不同的采购物品
- ✅ **尾款状态**：标记是否已付清尾款
- ✅ **发货状态**：标记是否已发货
- ✅ **模糊搜索**：支持搜索订单号、客户姓名、采购商、物品等多个字段
- ✅ **分页功能**：每页显示10条记录，支持快速翻页
- ✅ **云端同步**：支持Firebase实时数据库，多人可同时查看和编辑
- ✅ **本地存储**：未配置Firebase时自动使用本地存储
- ✅ **响应式设计**：支持桌面和移动设备

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 点击"添加采购记录"按钮添加新记录
3. 填写表单信息：
   - 客户姓名（必填）
   - 订单号（必填，且不能重复）
   - 采购项（可选，每个采购项包含采购商姓名和对应的采购物品）
   - 是否已付清尾款（复选框）
   - 是否已发货（复选框）
4. 点击"保存"按钮保存记录
5. 在表格中可以：
   - 查看所有采购记录
   - 点击"编辑"按钮修改记录
   - 点击"删除"按钮删除记录

## 数据存储

### 本地存储模式（默认）
- 所有数据存储在浏览器的本地存储（localStorage）中
- 刷新页面后数据仍然保留
- 数据仅保存在当前浏览器中

### 云端同步模式（可选）
- 支持Firebase Realtime Database实现云端同步
- 多人可同时查看和编辑数据
- 数据实时同步，无需刷新页面
- 配置方法请参考 `FIREBASE_SETUP.md` 文件

### 搜索功能
- 支持模糊搜索订单号、客户姓名、采购商姓名、采购物品
- 搜索结果实时显示，支持分页浏览
